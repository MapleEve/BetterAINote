# public 分层指南

## 目录职责

本目录用于运行时直接公开的静态资源。任何文件都可能被浏览器按原样访问，因此必须视为公开发布内容。

## 可改范围

- 可以新增公开图标、图片、manifest 相关静态文件和不含隐私的下载资源。
- 文件命名要稳定，避免与构建产物、设计证据或本地截图混用。
- 资源变更必须同步检查引用页面、缓存策略和可访问性文字。

## 禁止事项

- 禁止放入 design evidence、handoff zip、内部截图、录音、转写、数据库、token、Cookie、HAR 或私有 provider 返回。
- 禁止把测试夹具、调试输出或临时导出放进本目录。
- 禁止用 public 目录绕过 docs 或 src 的审查流程。

## 验证

- 运行 `git diff --check`。
- 检查文件可公开访问且不含私有信息。
- 改资源引用时运行相关页面或组件测试。
