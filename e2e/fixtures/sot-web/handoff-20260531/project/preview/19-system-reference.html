老定义的 .rack、.knob、.record-button、.settings-panel 来自早期录音机视觉。这次方向是「冷静的笔记本」，不是录音机硬件，所以多数应迁移或弃用。

类名原用途结论迁移到
.rack录音机机身金属面板弃用—（视觉不再用机身金属隐喻）

§ 12

双语用词 / Bilingual copy

用户界面用工程化术语会让人冷漠。下表是工程词 → 用户词的对照，写文案时直接抄。

不要这样写这样写说明
Sync · 同步更新 · 收新录音同步是工程师视角；用户只关心有没有新东西
Source · 来源来源（保留）用户能理解
Provider · 提供商来源 / 应用名「钉钉」「TicNote」，不要叫 provider
Transcript · 转写文本转写记录 / 文字稿「记录」更亲切
Speaker · 说话人说话人（保留）对的
Auth · 鉴权登录 / 授权不出现「鉴权」
Tenant / Workspace工作空间 / 个人空间不出现「租户」
Index · 索引整理中 / 准备搜索不出现「索引」
Embedding语义记号用户文档里也别出现
Latency · 延迟响应慢 / 几秒给数字
Notifications通知（保留）—

Skeleton state加载占位 / 加载中开发文档里可以叫 skeleton
§ 13

画布标注汇总 / Canvas annotations

这一节把前面 §03 / §04 / Data Sources 的对比 + 移动端弹层 + 旧视觉清理，串成一份「为什么这样画」的注释清单。给开发与新设计对齐用。

侧栏收缩
触发：用户点击底部 sync 区按钮 / 视口 ≤ 1023。
过渡：240px → 64px，--ease-out 220ms；导航标签淡出在前 100ms 完成；图标位置不动。
tooltip：仅在收缩态出现，hover 600ms；tooltip 用 --bg-elevated + --shadow-md；箭头朝左。
Dashboard 两栏 vs 三栏
≥ 1440：第三栏（详情）常驻 360px。列表 cell 紧凑。
1024–1439：默认两栏。点列表项后，列表压缩到 320px、详情滑入；再次点关闭按钮恢复两栏。
≤ 1023：详情走全屏覆盖，顶部留返回按钮。
Data Sources 双段 vs 三段
双段（默认）：设置 › 来源 直接给一份 5 个来源的列表 + 通用配置。适合已经稳定的用户。
三段（高级）：左列表 + 中间来源导航 + 右详情，支持单源精调。从 Tweaks 切到。
切换协议：变体由 Tweaks 写到 EDITMODE 块；下次刷新仍生效。
移动端弹层
设置：≤ 767 改为全屏页面，不是弹窗。
命令面板：≤ 767 走 sheet（底部弹），不走中央居中。
下拉：≤ 767 自动改为 action sheet，避免被键盘遮住。
旧视觉清理
录音机金属面板（rack）已弃用：新方向是冷静的笔记本，不要再用磁带 / 旋钮 / 机身高光。
红色录制圆按钮：仅在「快速记一下」窗口里出现，主界面没有。
VU 表 → level meter：简化成两条横线，颜色用 --signal-success，不再有金属细节。
